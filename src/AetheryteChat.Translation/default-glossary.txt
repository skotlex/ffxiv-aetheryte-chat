# 기본 용어집 — 플러그인과 함께 모든 사용자에게 배포된다.
# 한 줄에 '일본어 → 한국어' 하나. 한국 서버 유저들이 실제로 쓰는 말로 적는다.
# 한국어 쪽에 '|' 로 별칭을 더하면 보낼 때(한→일) 그 말도 찾는다. 첫 말은 받은 채팅(일→한) 번역에 쓴다.
# 별칭은 흔한 말 하나(예: '처음')로 두지 않는다 — '처음 뵙겠습니다' 같은 다른 뜻에도 걸린다.
# 원문에 글자가 들어 있기만 하면 걸리므로, 한 글자 약어(白·赤·ナ 등)나 흔한 말(なし·まとめ·捨てる·固定·エモ 등)은 넣지 않는다.
# 영문 약어는 앞뒤에 다른 영문자가 없을 때만 걸린다 (플레이어 이름 안의 st 등은 걸리지 않는다).
# 번역할 때는 그 줄에 나온 용어만 프롬프트에 넣으므로 용어가 늘어도 번역마다 쓰는 토큰은 거의 늘지 않는다.
# 같은 일본어가 두 번 나오면 뒤의 줄을 쓴다. 사용자가 '내 용어' 에 같은 일본어를 적으면 그쪽이 우선한다.
